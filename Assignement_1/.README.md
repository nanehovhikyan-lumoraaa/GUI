# Qt6 Text-Copy Dialog Application

A complete C++ desktop application built using the **Qt 6** framework[cite: 24]. This project implements a custom `problem` dialog widget inheriting from `QDialog` that features two line edits (one editable with a placeholder, one read-only) and interactive push buttons to copy text dynamically or close the window[cite: 25, 26, 27].

## Prerequisites

Before building and running the project, ensure you have:
* **C++ Compiler** supporting C++17 or later[cite: 24]
* **CMake** (version 3.16 or higher)[cite: 24]
* **Qt 6** (with the `Widgets` module)[cite: 24]

## Project Structure

* `CMakeLists.txt` — CMake build configuration file enabling `CMAKE_AUTOMOC`, specifying the project sources (`problem.cpp`, `problem.h`, `main.cpp`), and linking against Qt6 Widgets[cite: 24].
* `problem.h` — Header file containing the class declaration with the `Q_OBJECT` macro, constructor, private helper methods (`createdWidget`, `makeLayout`, `makeConnections`), slot (`fillText`), and UI pointer members[cite: 27].
* `problem.cpp` — Implementation file managing the layout arrangements, signal-slot connections, and the text replication logic between line edits[cite: 26].
* `main.cpp` — Application entry point initializing the `QApplication` and displaying the `problem` dialog window[cite: 25].

## Building and Running

1. **Create a build directory:**
   bash
   mkdir build
   cd build



2. **Configure the project with CMake:**
bash
cmake -S .. -B .




*(If Qt6 is in a custom location, add `-DCMAKE_PREFIX_PATH=/path/to/qt`)*
3. **Build the executable:**
bash
cmake --build .




4. **Run the application:**
* **Linux/macOS:** `./first`
* **Windows:** `.\first.exe` (or inside your generator's configuration folder like `Debug/first.exe`)
